# Smart PLE — Let's Learn

A mobile-first practice app for Ugandan Upper Primary learners (P.4–P.7).
One self-contained HTML file with every lesson, question and voice built in.

**Sign-in (Supabase) is required once, with internet.** After that the app keeps
working offline: a returning learner is recognised from their saved session and can
keep reading and practising (progress made offline is kept on the device).

## One command

```bash
cd ple-app
python3 tools/build_all.py
```

That runs the whole chain and stops at the first failure, so a broken dataset can never reach
a learner:

```
build papers -> build SST bank -> build Maths bank -> build Science bank
   -> build study notes -> build exercises
   -> validate EVERYTHING
   -> patch the UI modules -> embed all data in ple-app/index.html
   -> copy to ../index.html   (the deploy file at the repo root)
```

Commit **both** `index.html` files together. CI (`build-check`) runs the same build on
GitHub and fails the push if the committed files don't match a fresh build.

To just look at the app, open `ple-app/index.html` in any browser.

## Deploying

The deploy file is **`index.html` at the repo root** (regenerated by every build).
Commit and push, and your host redeploys it:

- **Vercel / Netlify:** set the Root Directory to the repo root (no subfolder).
- **GitHub Pages:** deploy from the `main` branch root.

The old `PLE-3-ready/` folder no longer exists — if your project still points at it,
update the Root Directory or the site will 404. After deploying, hard-refresh with
**Ctrl+Shift+R** — a normal refresh serves the cached old build.

## Ground rules the tooling enforces

- **Classes never mix.** Every practice question carries its class in the record *and* in its
  ID. Selectors re-check both, plus subject. Verified: 40,000 questions served, 0 leaks.
- **Maths is never wrong.** Each Maths question stores a `calc` expression that
  `validate_math.py` re-evaluates independently. 749 checked, 0 disagreements.
- **Past papers are archives.** Wording is preserved verbatim, including original grammar.
  Nothing is rewritten, and no question claims UNEB origin until a human verifies it.
- **No phantom visuals.** A question referring to "the map below" without a real image file
  is a build error.
