# TOPIC 1: SET CONCEPTS

*Curriculum reference: NCDC Primary Five Curriculum, Set One, Mathematics Theme 1,

**What you already know:** In P.3 and P.4 you formed sets of objects and counted their

**union** and **intersection** on a **Venn diagram**.

**By the end of this topic you should be able to:**

- form sets and describe them

- name the empty set
- find the union and the intersection of two sets
- draw a Venn diagram and read members from it

---

## 1. WHAT A SET IS

**Set:** A group of things that belong together. The things in the set are its **members**
(also called **elements**). A set is written inside **curly brackets { }** and given a
capital letter as its name.

```
A = {2, 4, 6, 8}
```

We read this as: *"Set A is the set of two, four, six and eight."*

- **n(A)** means *the number of members of set A*. Here **n(A) = 4**.
- **∈** means *is a member of*. So 6 ∈ A.
- **∉** means *is not a member of*. So 5 ∉ A.

### Describing a set

A set can be written in **two ways**:

| Way | Example |
|---|---|
| By **listing** the members | B = {Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday} |
| By **describing** them in words | B = the set of days of the week |

---

## 2. EQUAL SETS AND EQUIVALENT SETS

**Equal sets:** Two sets that have **exactly the same members**. The order does not matter.

```
P = {a, b, c}      Q = {c, a, b}      →  P = Q
```

**Equivalent sets:** Two sets that have **the same number of members**, but the members
themselves may be different. The sign used is **↔**.

```
R = {1, 2, 3}      S = {cat, dog, goat}      n(R) = 3, n(S) = 3   →  R ↔ S
```

| | Equal sets | Equivalent sets |
|---|---|---|
| Members | Exactly the same | May be different |
| Number of members | The same | The same |
| Sign | = | ↔ |

**Remember:** All equal sets are also equivalent, but **equivalent sets are not always
equal**.

---

## 3. THE EMPTY SET

**Empty set:** A set with **no members at all**. It is written as **{ }** or **∅**.

Examples of empty sets:

- the set of pupils in P.5 who are 100 years old
- the set of cows with six legs
- the set of even numbers between 4 and 6

For the empty set, **n(∅) = 0**.

> Careful: {0} is **not** the empty set. It is a set with one member — the number 0.

---

## 4. UNION OF SETS

**Union (∪):** The set of **all** the members found in either set, or in both. A member is
written **only once**.

```
A = {2, 4, 6, 8}        B = {4, 8, 12}
A ∪ B = {2, 4, 6, 8, 12}
n(A ∪ B) = 5
```

---

## 5. INTERSECTION OF SETS

**Intersection (∩):** The set of members that are found in **both** sets — the members the
two sets share.

```
A = {2, 4, 6, 8}        B = {4, 8, 12}
A ∩ B = {4, 8}
n(A ∩ B) = 2
```

If two sets share no members at all, their intersection is the **empty set**.

```
C = {1, 3, 5}     D = {2, 4}     C ∩ D = { }
```

---

## 6. VENN DIAGRAMS

A **Venn diagram** shows sets as rings inside a rectangle. Where the rings overlap, the
members belong to **both** sets.

```
   ------------------------------
  |   A                B         |
  |  ______        ______        |
  | /      \      /      \       |
  | |  2   |  4  |   12  |       |
  | |  6   |  8  |       |       |
  | \______/     \______/        |
  |                              |
   ------------------------------
```

- The **overlap** (4 and 8) is **A ∩ B**.
- **Everything inside both rings** (2, 6, 4, 8, 12) is **A ∪ B**.
- 2 and 6 are in **A only**. 12 is in **B only**.

### A useful check

```
n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
         = 4 + 3 − 2
         = 5   ✓
```

We take away the intersection once because those members were counted twice.

### Worked example

In a class of 30 pupils, 18 play football, 14 play netball and 6 play **both** games.
How many pupils play only football?

```
Only football = 18 − 6 = 12 pupils
Only netball  = 14 − 6 = 8 pupils
Check: 12 + 6 + 8 = 26 pupils play a game
       30 − 26 = 4 pupils play neither game
```

**Answer: 12 pupils play only football.**

# KEY DEFINITIONS

| Term | Meaning |
|---|---|
| Set | A group of things that belong together |
| Member (element) | One of the things in a set |
| n(A) | The number of members in set A |
| Equal sets | Sets with exactly the same members |
| Equivalent sets | Sets with the same number of members |
| Empty set | A set with no members, written { } or ∅ |
| Union (∪) | All members of both sets, each written once |
| Intersection (∩) | The members found in both sets |
| Venn diagram | A drawing that shows sets as rings |

---

# IMPORTANT FACTS TO REMEMBER

- A set is written in **curly brackets { }**.
- A member is never written **twice** in the same set.
- The **order** of members does not change the set.
- **Equal** means the same members; **equivalent** means the same *number* of members.
- n(∅) = **0**, but n({0}) = **1**.
- The **overlap** on a Venn diagram is the **intersection**.
- n(A ∪ B) = n(A) + n(B) − n(A ∩ B).

---

# EXAMINATION POINTS

- Given A = {2, 4, 6, 8} and B = {4, 8, 12}: A ∪ B = {2, 4, 6, 8, 12} and A ∩ B = {4, 8}.
- {1, 2, 3} and {3, 2, 1} are **equal** sets.
- {a, b} and {5, 9} are **equivalent** sets.
- "The set of men with three heads" is the **empty set**.
- Always count the members carefully when asked for n(A).
- In a word problem, put the **"both" number in the overlap first**, then subtract.

---

# COMMON MISTAKES TO AVOID

- Writing a repeated member twice in a union.
- Confusing ∪ (union) with ∩ (intersection) — **∪ is like a cup that holds everything**.
- Saying {0} is the empty set.
- Forgetting to subtract the "both" group when filling a Venn diagram.
- Leaving out the curly brackets when writing an answer.

# REVISION QUESTIONS

1. Write in set notation: the set of vowels in the English alphabet.
2. Given M = {3, 6, 9, 12}, find n(M).
3. Are {p, q, r} and {r, q, p} equal or equivalent? Explain.
4. Are {1, 2, 3, 4} and {w, x, y, z} equal or equivalent?
5. Write one example of an empty set.
6. Given A = {1, 2, 3, 4} and B = {3, 4, 5}, find A ∪ B.
7. Using the sets in question 6, find A ∩ B.
8. Using the sets in question 6, find n(A ∪ B).
9. Given C = {2, 4} and D = {5, 7}, find C ∩ D.
10. If n(P) = 7, n(Q) = 5 and n(P ∩ Q) = 3, find n(P ∪ Q).
11. Set X = {even numbers between 1 and 11}. List its members.
12. Set Y = {factors of 12}. List its members.
13. Using X and Y from questions 11 and 12, find X ∩ Y.
14. In a class, 20 pupils like maize, 15 like beans and 8 like both. How many like only maize?
15. Using question 14, how many pupils like only beans?

---

# ANSWERS TO REVISION QUESTIONS

1. **{a, e, i, o, u}**
2. **n(M) = 4**
3. **Equal** — they have exactly the same members, and order does not matter.
4. **Equivalent** — each has 4 members, but the members are different.
5. Any true example, for example **the set of pupils in P.5 who are 100 years old** (or: cows with six legs).
6. A ∪ B = **{1, 2, 3, 4, 5}**
7. A ∩ B = **{3, 4}**
8. n(A ∪ B) = **5**
9. C ∩ D = **{ }** (the empty set)
10. 7 + 5 − 3 = **9**
11. X = **{2, 4, 6, 8, 10}**
12. Y = **{1, 2, 3, 4, 6, 12}**
13. X ∩ Y = **{2, 4, 6}**
14. 20 − 8 = **12 pupils**
15. 15 − 8 = **7 pupils**

# P.5 QUICK REVISION

- Set = { } · member ∈ · number of members n(A)
- **Equal** = same members · **Equivalent** = same number
- Empty set = { } or ∅ · n(∅) = 0
- **∪ union** = everything · **∩ intersection** = the overlap
- n(A ∪ B) = n(A) + n(B) − n(A ∩ B)
