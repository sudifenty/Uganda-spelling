**By the end of this topic you should be able to:**

- solve simple equations with one unknown
- solve simple word problems using algebra

## 1. TRUE AND FALSE MATHEMATICAL STATEMENTS

A mathematical statement is **true** when both sides have the same value.

| Statement | True or false | Why |
|---|---|---|
| 7 + 5 = 12 | **True** | Both sides are 12 |
| 9 − 4 = 6 | **False** | 9 − 4 is 5, not 6 |
| 6 × 3 = 18 | **True** | Both sides are 18 |
| 20 ÷ 4 = 6 | **False** | 20 ÷ 4 is 5 |

When a number is missing we put a **letter** in its place and call it the **unknown**.

```
5 + __ = 9      becomes      5 + n = 9      and      n = 4
```

---

## 2. THE WORDS OF ALGEBRA

| Word | Meaning | Example |
|---|---|---|
| **Variable (unknown)** | The letter that stands for a number | the *n* in 5 + n = 9 |
| **Term** | A number, a letter, or a number and a letter joined by × | 5a, 3, y |
| **Coefficient** | The number in front of the letter | in 7m the coefficient is 7 |
| **Expression** | Terms joined by + or −, with no equals sign | 3a + 5 |
| **Equation** | Two expressions joined by an equals sign | 3a + 5 = 20 |

**Note:** 5 × a is written **5a**, and a × a is written **a²**. A letter on its own, like
*m*, means **1m**.

---

## 3. LIKE TERMS

**Like terms** are terms that use **the same letter**. Only like terms can be added or
subtracted.

| Like terms | Unlike terms |
|---|---|
| 5a and 3a | 5a and 3b |
| 7m, m, 2m | 4x and 4 |

### Collecting like terms

```
5a + 3a = 8a
9y − 4y = 5y
7x − 2x + 4 = 5x + 4
3m + 2n + 5m − n = 8m + n
6p + 4 − 2p + 3 = 4p + 7
```

**Work carefully:**

```
3m + 2n + 5m − n
m terms: 3m + 5m = 8m
n terms: 2n − n  = 1n = n
Answer: 8m + n
```

> **You cannot add 5a and 3b.** They are different things — like adding 5 goats and 3 chairs.

## 4. FORMING ALGEBRAIC EXPRESSIONS

| In words | In algebra |
|---|---|
| A number increased by 8 | n + 8 |
| A number decreased by 5 | n − 5 |
| Twice a number | 2n |
| Three times a number, plus 4 | 3n + 4 |
| A number shared among 4 | n ÷ 4 or n/4 |
| The sum of a number and 7 | n + 7 |
| 6 less than a number | n − 6 |

**Example.** Ali has *x* mangoes. Ben has 5 more than Ali. Write what Ben has and what they
have altogether.

```
Ben:        x + 5
Altogether: x + (x + 5) = 2x + 5
```

---

## 5. SOLVING SIMPLE EQUATIONS

To solve an equation, get the letter **alone on one side**. Whatever you do to one side you
must do to the **other side too**.

### Type 1 — addition

```
x + 7 = 12
x + 7 − 7 = 12 − 7
x = 5
Check: 5 + 7 = 12  ✓
```

### Type 2 — subtraction

```
y − 4 = 9
y − 4 + 4 = 9 + 4
y = 13
Check: 13 − 4 = 9  ✓
```

### Type 3 — multiplication

```
3m = 21
3m ÷ 3 = 21 ÷ 3
m = 7
Check: 3 × 7 = 21  ✓
```

### Type 4 — division

```
n ÷ 4 = 6
n = 6 × 4
n = 24
Check: 24 ÷ 4 = 6  ✓
```

### Type 5 — two steps

```
2p − 5 = 9
2p = 9 + 5
2p = 14
p = 7
Check: (2 × 7) − 5 = 14 − 5 = 9  ✓
```

```
4k + 3 = 23
4k = 23 − 3 = 20
k = 5
Check: (4 × 5) + 3 = 23  ✓
```

## 6. WORD PROBLEMS USING ALGEBRA

**Steps:** let the unknown be a letter → write the equation → solve it → **check** → answer
in words.

**Example 1.** A number increased by 8 gives 20. Find the number.

```
Let the number be n
n + 8 = 20
n = 12
Check: 12 + 8 = 20  ✓
```

**Example 2.** Three times a number, less 4, gives 17. Find the number.

```
Let the number be x
3x − 4 = 17
3x = 21
x = 7
Check: (3 × 7) − 4 = 17  ✓
```

**Example 3.** Mary has *y* books. Her sister has twice as many. Together they have 27
books. How many has Mary?

```
y + 2y = 27
3y = 27
y = 9
Mary has 9 books and her sister has 18.
Check: 9 + 18 = 27  ✓
```

# KEY DEFINITIONS

| Term | Meaning |
|---|---|
| Algebra | Using letters to stand for unknown numbers |
| Variable (unknown) | The letter that stands for a number |
| Term | A single number or letter in an expression |
| Coefficient | The number written in front of a letter |
| Like terms | Terms that use the same letter |
| Expression | Terms joined by + or −, with no equals sign |
| Equation | A statement that two expressions are equal |
| Solve | To find the value of the unknown |
| Simplify | To collect like terms and write the shortest form |

---

# IMPORTANT FACTS TO REMEMBER

- **Only like terms can be collected.**
- 5 × a is written **5a**; the letter *m* alone means **1m**.
- An **expression** has no equals sign; an **equation** does.
- Whatever you do to one side of an equation, do to the **other side too**.
- To undo **+** use **−**; to undo **×** use **÷**.
- Always **check** by putting your answer back into the equation.
- "Twice" means **× 2**; "the sum of" means **+**.

---

# EXAMINATION POINTS

- 5a + 3a = **8a**.
- 3m + 2n + 5m − n = **8m + n**.
- x + 7 = 12 gives **x = 5**.
- 3m = 21 gives **m = 7**.
- 2p − 5 = 9 gives **p = 7**.
- "A number increased by 8 is 20" gives n + 8 = 20 and **n = 12**.
- Always show the checking line.

---

# COMMON MISTAKES TO AVOID

- Adding unlike terms, for example writing 5a + 3b = 8ab.
- Forgetting that a lone letter counts as 1 of that letter.
- Changing only one side of the equation.
- Using + when you should use − to undo an operation.
- Writing the answer as 7x when the question asks for the value of x.
- Not checking the answer.

# P.5 QUICK REVISION

- Letters stand for unknown numbers
- Collect **like terms** only · m means 1m
- Expression has no **=** · equation has **=**
- Do the same thing to **both sides**
- Undo + with − · undo × with ÷
- Always **check** your answer
