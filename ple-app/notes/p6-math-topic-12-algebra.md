## 1. THE LANGUAGE OF ALGEBRA

### Definitions

**Algebra:** The part of Mathematics in which letters stand for unknown numbers.

**Variable (unknown):** The letter used, such as x, y, a or n.

**Term:** A single part of an expression. In 5a + 3b, the terms are 5a and 3b.

**Like terms:** Terms with exactly the same letter — 4x and 7x.

**Unlike terms:** Terms with different letters — 4x and 7y.

**Coefficient:** The number in front of the letter. In 8y, the coefficient is 8.

**Expression:** A group of terms with **no equals sign** — 3x + 5.

**Equation:** A statement **with an equals sign** — 3x + 5 = 20.

### How we write things in algebra

| We say | We write |
|---|---|
| 5 times y | 5y |
| y multiplied by y | y² |
| y divided by 4 | y/4 |
| 7 more than y | y + 7 |
| 7 less than y | y − 7 |
| Twice y, plus 3 | 2y + 3 |
| A number shared among 5 people | n/5 |

## 2. SIMPLIFYING EXPRESSIONS

**Only like terms can be added or subtracted.**

| Expression | Simplified |
|---|---|
| 6a + 5a | **11a** |
| 12y − 4y | **8y** |
| 7x + 3y − 2x + 5y | **5x + 8y** |
| 9m + 4 − 3m − 1 | **6m + 3** |
| 8k + 3p − 8k | **3p** |

**Removing brackets:** multiply everything inside by what is outside.

- 4(x + 3) = **4x + 12**
- 5(2a − 1) = **10a − 5**
- 3(x + 2) + 2(x + 4) = 3x + 6 + 2x + 8 = **5x + 14**

**Careful:** 3a + 4b **cannot** be simplified — they are unlike terms.

---

## 3. SUBSTITUTION

**Substitution** means replacing the letters with their number values and working out the
answer, using **BODMAS**.

*Given a = 5, b = 3 and c = 2:*

| Expression | Working | Answer |
|---|---|---|
| a + b | 5 + 3 | **8** |
| 3a − 2b | 15 − 6 | **9** |
| abc | 5 × 3 × 2 | **30** |
| a² + c | 25 + 2 | **27** |
| (a + b) ÷ c | 8 ÷ 2 | **4** |
| 4b − c² | 12 − 4 | **8** |

## 4. SOLVING SIMPLE EQUATIONS

### The golden rule

**Whatever you do to one side, do to the other side.** Undo addition with subtraction, and
undo multiplication with division. Always **check** your answer.

### Worked examples

1. *x + 7 = 15* → x = 15 − 7 = **8**
2. *y − 6 = 11* → y = 11 + 6 = **17**
3. *5n = 45* → n = 45 ÷ 5 = **9**
4. *m/4 = 6* → m = 6 × 4 = **24**
5. *3x + 4 = 19* → 3x = 15 → x = **5**
   *Check:* 3(5) + 4 = 19 ✓
6. *2y − 5 = 13* → 2y = 18 → y = **9**
7. *4(k + 2) = 28* → 4k + 8 = 28 → 4k = 20 → k = **5**
8. *7x = 3x + 16* → 7x − 3x = 16 → 4x = 16 → x = **4**

## 5. WORD PROBLEMS

**Method:** let the unknown be a letter → form the equation → solve it → check the answer
against the words.

1. *A number added to 9 gives 23. Find the number.*
   n + 9 = 23 → n = **14**

2. *Three times a number, less 5, gives 25. Find the number.*
   3n − 5 = 25 → 3n = 30 → n = **10**

3. *Musa is 4 years older than Ann. Together they are 26 years old. Find their ages.*
   Let Ann be x → x + (x + 4) = 26 → 2x + 4 = 26 → 2x = 22 → x = 11.
   **Ann is 11 and Musa is 15** (11 + 15 = 26 ✓)

4. *A pen costs x shillings and a book costs three times as much. Together they cost 8,000
   shillings. Find the cost of each.*
   x + 3x = 8,000 → 4x = 8,000 → x = 2,000.
   **Pen 2,000 shillings; book 6,000 shillings**

5. *The perimeter of a rectangle is 30 m. Its length is twice its width. Find both.*
   2(w + 2w) = 30 → 6w = 30 → w = 5. **Width 5 m, length 10 m**

| Term | A single part of an expression |
| Like terms | Terms with exactly the same letter |
| Coefficient | The number in front of a letter |

| Equation | A mathematical statement with an equals sign |
| Substitution | Replacing letters with their number values |
| Solution | The value of the unknown that makes the equation true |

---

# IMPORTANT FACTS TO REMEMBER

- Only **like terms** can be added or subtracted; 3a + 4b stays as it is.
- Multiply **everything** inside a bracket by the term outside.
- Whatever you do to one side of an equation, **do to the other**.
- When a term crosses the equals sign, its **sign changes**.
- Always **check** by putting your answer back into the equation.
- Use **BODMAS** when substituting.
- An expression has **no** equals sign; an equation has one.

---

# EXAMINATION POINTS

- Simplify 7x + 3y − 2x + 5y → **5x + 8y**.
- Remove brackets: 4(x + 3) → **4x + 12**.
- If a = 5 and b = 3, then 3a − 2b = **9**.
- Solve 3x + 4 = 19 → **x = 5**.
- Solve 7x = 3x + 16 → **x = 4**.
- "A number added to 9 gives 23" → n + 9 = 23 → **14**.

---

# COMMON MISTAKES TO AVOID

- Writing 3a + 4b = 7ab.
- Multiplying only the first term inside a bracket.
- Forgetting to change the sign when a term crosses the equals sign.
- Dividing only one side of the equation.
- Not checking the answer, so a slip goes unnoticed.

# P.6 QUICK REVISION

- Add only **like terms** · multiply the **whole** bracket
- Substitute, then use **BODMAS**
- Equation: do the same to **both sides**; a term crossing the equals sign **changes sign**
- Always **check** your answer
- Word problems: **let the unknown be a letter**, form the equation, solve, check
