## 1. FINITE AND INFINITE SETS

### Definitions

**Set:** A collection of things that belong together. Members are written inside curly brackets `{ }`.

**Finite set:** A set whose members can be counted and come to an end.

**Infinite set:** A set whose members go on and on without ending.

### Examples

| Set | Type | Why |
|---|---|---|
| A = {1, 2, 3, 4, 5} | Finite | It has exactly 5 members |
| B = {days of the week} | Finite | It has 7 members |
| C = {1, 2, 3, 4, …} | Infinite | Counting numbers never end |
| D = {even numbers} | Infinite | They never end |
| E = { } or ∅ | Finite (empty) | It has 0 members |

**Note:** `n(A)` means "the number of members of set A". For A above, n(A) = 5.

## 2. SUBSETS

### Definitions

**Subset:** A set whose members all come from another set. We write A ⊂ B.

**Proper subset:** A subset that is **not** the whole set itself.

**Improper subset:** The set itself. Every set is a subset of itself.

### Example

Given P = {a, b, c}, all its subsets are:

{ }, {a}, {b}, {c}, {a, b}, {a, c}, {b, c}, {a, b, c}

That is **8 subsets** in total: 7 proper subsets and 1 improper subset ({a, b, c}).

### The rule (work it out, do not just memorise)

| Members (n) | Subsets counted | Pattern |
|---|---|---|
| 1 | 2 | 2¹ |
| 2 | 4 | 2² |
| 3 | 8 | 2³ |
| 4 | 16 | 2⁴ |

**Number of subsets = 2ⁿ**, where n is the number of members.
**Number of proper subsets = 2ⁿ − 1.**

### Worked example

*A set has 5 members. How many subsets does it have? How many are proper subsets?*

Subsets = 2⁵ = **32**. Proper subsets = 32 − 1 = **31**.

## 3. VENN DIAGRAMS OF TWO SETS

A Venn diagram uses circles inside a rectangle (the universal set, ε) to show how two sets
are related.

### The four regions of a two-set Venn diagram

| Region | Meaning |
|---|---|
| A only | Members in A but not in B |
| A ∩ B | Members in **both** A and B |
| B only | Members in B but not in A |
| Outside both | Members in neither A nor B |

### The formula

**n(A ∪ B) = n(A) + n(B) − n(A ∩ B)**

We subtract n(A ∩ B) because the members in both sets were counted twice.

### Worked example 1

*In a class of 40 pupils, 25 play football, 20 play netball and 8 play both games.
How many pupils play neither game?*

- Football only = 25 − 8 = **17**
- Netball only = 20 − 8 = **12**
- Play at least one game = 17 + 8 + 12 = **37**
- Play neither = 40 − 37 = **3 pupils**

*Check with the formula:* n(F ∪ N) = 25 + 20 − 8 = 37. Then 40 − 37 = 3. ✓

### Worked example 2

*In a group of 60 people, 35 like tea, 30 like coffee and 5 like neither.
How many like both drinks?*

- People who like at least one drink = 60 − 5 = 55
- Let both = x. Then 35 + 30 − x = 55 → 65 − x = 55 → **x = 10 people**

## 4. PROBABILITY

### Definition

**Probability:** The chance that something will happen. It is written as a fraction:

**Probability = (number of favourable outcomes) ÷ (total number of possible outcomes)**

### Important Points

- Probability is always between **0 and 1**.
- Probability **0** means it can never happen; probability **1** means it must happen.
- Always give the answer as a fraction in its simplest form unless told otherwise.

### Worked examples

1. *A bag has 5 red balls and 7 blue balls. One ball is picked without looking.
   What is the probability that it is red?*
   Total = 5 + 7 = 12. P(red) = **5/12**

2. *A fair die is thrown once. What is the probability of getting an even number?*
   Even numbers on a die: 2, 4, 6 → 3 out of 6. P(even) = 3/6 = **1/2**

3. *Using the class of 40 above, what is the probability that a pupil picked at random
   plays both games?*
   P(both) = 8/40 = **1/5**

# KEY DEFINITIONS

| Term | Meaning |
|---|---|
| Set | A collection of things that belong together |
| Finite set | A set whose members can be counted and come to an end |
| Infinite set | A set whose members never end |
| Empty set | A set with no members, written { } or ∅ |
| Subset | A set whose members all come from another set |
| Proper subset | Any subset except the set itself |
| Improper subset | The set itself |
| Union (∪) | All members of both sets, counted once |
| Intersection (∩) | Members found in both sets |
| Probability | The chance that an event will happen |

---

# IMPORTANT FACTS TO REMEMBER

- Number of subsets = **2ⁿ**; number of proper subsets = **2ⁿ − 1**.
- The empty set { } is a subset of **every** set.
- **n(A ∪ B) = n(A) + n(B) − n(A ∩ B)**.
- "A only" = n(A) − n(A ∩ B).
- Probability = favourable outcomes ÷ total outcomes, and always lies between 0 and 1.
- A die has 6 faces; a coin has 2 faces; an ordinary week has 7 days.

---

# EXAMINATION POINTS

- A set with 4 members has 16 subsets and 15 proper subsets.
- The empty set has exactly 1 subset (itself).
- In word problems, "both" always goes in the **middle** of the Venn diagram first.
- "Neither" is written **outside** the two circles but inside the rectangle.
- Simplify probability fractions: 8/40 = 1/5.

---

# COMMON MISTAKES TO AVOID

- Writing 25 in the football circle when 8 of them also play netball — put **17** in "football only".
- Forgetting to subtract the intersection when using n(A ∪ B).
- Giving probability as a whole number — it must be a fraction (or decimal) between 0 and 1.
- Counting the set itself as a proper subset.

# REVISION QUESTIONS

1. Define a finite set and give one example.
2. Give one example of an infinite set.
3. List all the subsets of the set {p, q}.
4. How many subsets has a set with 6 members?

10. A die is thrown once. What is the probability of getting a number greater than 4?
11. What is the probability of picking a vowel from the letters of the word MATHEMATICS?
12. Write down the members of the set of prime numbers less than 10, and state whether it is finite or infinite.
13. If a set has 32 subsets, how many members has it?
14. In a class of 40 pupils, 22 like posho only, 9 like both posho and rice, and 4 like neither. How many like rice altogether?
15. A letter is chosen from the word UGANDA. Find the probability that it is the letter A.

# ANSWERS TO REVISION QUESTIONS

1. A finite set is a set whose members can be counted and come to an end, for example {1, 2, 3, 4}.
2. The set of counting numbers {1, 2, 3, …} — any set that never ends is acceptable.
3. { }, {p}, {q}, {p, q}.
4. 2⁶ = **64 subsets**.
5. 2⁴ − 1 = 16 − 1 = **15 proper subsets**.
6. n(A ∪ B) = 18 + 14 − 6 = **26**.
7. Study at least one = 30 + 25 − 10 = 45. Neither = 50 − 45 = **5 pupils**.
8. At least one crop = 45 − 3 = 42. Both = 28 + 24 − 42 = **10 farmers**.
9. Total = 4 + 6 = 10. P(green) = 4/10 = **2/5**.
10. Numbers greater than 4 are 5 and 6 → 2 out of 6. P = 2/6 = **1/3**.
11. MATHEMATICS has 11 letters; the vowels are A, E, A, I → 4. P = **4/11**.
12. {2, 3, 5, 7} — it is a **finite** set with 4 members.
13. 2ⁿ = 32, and 2⁵ = 32, so the set has **5 members**.
14. Pupils who like at least one = 40 − 4 = 36. Rice altogether = 36 − 22 = **14 pupils**.
15. UGANDA has 6 letters and the letter A appears 3 times. P = 3/6 = **1/2**.
