## 1. NUMBERS UP TO 99,999,999

### Place value chart

| Place | Ten millions | Millions | Hundred thousands | Ten thousands | Thousands | Hundreds | Tens | Ones |
|---|---|---|---|---|---|---|---|---|
| Digit | 4 | 5 | 3 | 0 | 8 | 6 | 1 | 2 |

The number above is **45,308,612**.

### Definitions

**Place value:** The position of a digit in a number (ones, tens, hundreds …).

**Value:** The place value multiplied by the digit itself.

### Worked examples

1. *Write 45,308,612 in words.*
   **Forty-five million, three hundred eight thousand, six hundred twelve.**

2. *In the number 6,742,905, what is the place value of 7? What is its value?*
   Place value = **hundred thousands**. Value = 7 × 100,000 = **700,000**.

3. *Write in figures: Eighty-three million, four hundred sixty thousand, fifty.*
   **83,460,050**

### Important Points

- Grouping in threes from the right makes reading easy: 45 | 308 | 612.
- Write a **zero** as a place holder wherever a place is empty.
- The biggest 8-digit number is 99,999,999; the smallest is 10,000,000.

## 2. ROMAN NUMERALS UP TO MM

### The symbols

| Roman | I | V | X | L | C | D | M |
|---|---|---|---|---|---|---|---|
| Value | 1 | 5 | 10 | 50 | 100 | 500 | 1,000 |

### The rules

1. A symbol may be repeated up to **three** times: III = 3, XXX = 30.
2. **V, L and D are never repeated.**
3. When a smaller value comes **before** a bigger one, you **subtract**: IV = 4, IX = 9, XL = 40, XC = 90, CD = 400, CM = 900.
4. When a smaller value comes **after** a bigger one, you **add**: VI = 6, LX = 60, MC = 1,100.
5. Only I, X and C are used for subtracting.

### Worked examples

| Number | Roman numeral | Working |
|---|---|---|
| 49 | **XLIX** | 40 (XL) + 9 (IX) |
| 94 | **XCIV** | 90 (XC) + 4 (IV) |
| 1994 | **MCMXCIV** | 1000 + 900 + 90 + 4 |
| 2000 | **MM** | 1000 + 1000 |
| 1,649 | **MDCXLIX** | 1000 + 500 + 100 + 40 + 9 |

*Change CDLXXVII to Hindu-Arabic:* CD = 400, L = 50, XX = 20, V = 5, II = 2 →
400 + 50 + 20 + 5 + 2 = **477**.

## 3. BASES

### Definition

**Base:** The number of digits used in a number system. Base ten uses 0–9; base two (binary) uses only 0 and 1; base five uses 0–4.

### Changing from another base to base ten

Multiply each digit by the base raised to its position value, starting from 0 on the right.

**Example 1:** Change 1101₂ to base ten.
1×2³ + 1×2² + 0×2¹ + 1×2⁰ = 8 + 4 + 0 + 1 = **13₁₀**

**Example 2:** Change 234₅ to base ten.
2×5² + 3×5¹ + 4×5⁰ = 50 + 15 + 4 = **69₁₀**

### Changing from base ten to another base

Divide again and again by the base and read the remainders **upwards**.

**Example:** Change 25₁₀ to base two.

| Divide | Answer | Remainder |
|---|---|---|
| 25 ÷ 2 | 12 | 1 |
| 12 ÷ 2 | 6 | 0 |
| 6 ÷ 2 | 3 | 0 |
| 3 ÷ 2 | 1 | 1 |
| 1 ÷ 2 | 0 | 1 |

Reading the remainders upwards: **11001₂**
*Check:* 16 + 8 + 0 + 0 + 1 = 25 ✓

## 4. WORKING IN THE BINARY SYSTEM

Only the digits **0 and 1** are used. Remember: 1 + 1 = 10₂ (write 0, carry 1).

### Addition

```
    1 0 1 1        (11)
  +   1 1 0        ( 6)
  ----------
    1 0 0 0 1      (17)
```
*Check in base ten:* 11 + 6 = 17, and 17 = 10001₂ ✓

### Subtraction

```
    1 0 1 0        (10)
  -   1 1 1        ( 7)
  ----------
      0 1 1        ( 3)
```
When you cannot subtract, borrow from the next column; one borrowed unit is worth **two**.

### Multiplication

```
      1 0 1        (5)
    ×   1 1        (3)
    --------
      1 0 1
    1 0 1
    --------
    1 1 1 1        (15)
```
*Check:* 5 × 3 = 15, and 15 = 1111₂ ✓

# KEY DEFINITIONS

| Term | Meaning |
|---|---|
| Place value | The position of a digit in a number |
| Value | The digit multiplied by its place value |
| Roman numerals | The number system using I, V, X, L, C, D and M |
| Hindu-Arabic numerals | The ordinary numbers 0, 1, 2, 3 … |
| Base | The number of digits used in a number system |
| Binary system | The base two system, which uses only 0 and 1 |
| Bicimal / digit | Each single figure in a number |

---

# IMPORTANT FACTS TO REMEMBER

- 99,999,999 is the largest 8-digit number.
- M = 1,000, so **MM = 2,000**; CM = 900 and CD = 400.
- V, L and D are **never** repeated and are **never** used for subtracting.
- Base ten digits: 0–9. Base two: 0 and 1. Base five: 0–4. A digit is always **smaller than the base**.
- To change to base ten, **multiply** by powers of the base; to change from base ten, **divide** by the base and read remainders upwards.
- In binary: 1 + 1 = 10, and 1 + 1 + 1 = 11.

---

# EXAMINATION POINTS

- Write in words / write in figures — watch out for zeros as place holders.
- Value of a digit = digit × place value.
- MM = 2000; MCMXCIV = 1994.
- 1101₂ = 13₁₀; 25₁₀ = 11001₂.
- Any base written as digits must never use a digit as big as the base (there is no digit 5 in base five).

---

# COMMON MISTAKES TO AVOID

- Writing IIII for 4 instead of **IV**.
- Writing VV for 10 — V is never repeated; use **X**.
- Forgetting the zero in numbers like 83,460,050.
- In binary addition, writing 2 — there is no digit 2 in base two; write 0 and carry 1.
- Reading division remainders downwards instead of **upwards**.

12. Subtract: 1100₂ − 101₂.

# ANSWERS TO REVISION QUESTIONS

1. Thirty-seven million, four hundred five thousand, two hundred six.
2. **52,700,409**
3. 8 is in the millions place, so its value is 8 × 1,000,000 = **8,000,000**.
4. 1,984 = 1000 + 900 + 80 + 4 = **MCMLXXXIV**
5. MM = 2000, CD = 400, XL = 40, V = 5 → **2,445**
6. XC = 90, V = 5, II = 2 → **97**
7. 1×8 + 0×4 + 1×2 + 1×1 = **11₁₀**
8. 3×25 + 4×5 + 2 = 75 + 20 + 2 = **97₁₀**
9. 19 ÷ 2 = 9 r 1; 9 ÷ 2 = 4 r 1; 4 ÷ 2 = 2 r 0; 2 ÷ 2 = 1 r 0; 1 ÷ 2 = 0 r 1 → **10011₂** (16 + 2 + 1 = 19 ✓)
10. 47 ÷ 5 = 9 r 2; 9 ÷ 5 = 1 r 4; 1 ÷ 5 = 0 r 1 → **142₅** (25 + 20 + 2 = 47 ✓)
11. 13 + 11 = 24 → **11000₂**
12. 12 − 5 = 7 → **111₂**
13. 6 × 3 = 18 → **10010₂**
14. 1111₂ = 8 + 4 + 2 + 1 = 15; 21₅ = 2×5 + 1 = 11. So **1111₂ is bigger**.
15. Largest = **99,999,999**; smallest = **10,000,000**.

# P.7 QUICK REVISION

- Group digits in **threes** to read big numbers
- **MM = 2000** · CM = 900 · CD = 400 · V, L, D never repeat
- Other base → base ten: **multiply** by powers of the base
- Base ten → other base: **divide**, read remainders **upwards**
