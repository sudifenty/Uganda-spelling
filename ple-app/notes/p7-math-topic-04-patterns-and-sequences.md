## 1. TESTS OF DIVISIBILITY

### Definition

**Divisible:** A number is divisible by another when it divides exactly, leaving no remainder.

| Divisible by | Test | Example |
|---|---|---|
| **2** | The last digit is even (0, 2, 4, 6, 8) | 1,234 |
| **3** | The sum of the digits is divisible by 3 | 4,521 → 4+5+2+1 = 12 ✓ |
| **4** | The last **two** digits form a number divisible by 4 | 3,116 → 16 ✓ |
| **5** | The last digit is 0 or 5 | 8,475 |
| **6** | The number is divisible by **both 2 and 3** | 4,530 |
| **8** | The last **three** digits form a number divisible by 8 | 7,104 → 104 ✓ |
| **9** | The sum of the digits is divisible by 9 | 5,634 → 5+6+3+4 = 18 ✓ |
| **10** | The last digit is 0 | 6,780 |
| **11** | The difference between the sum of the odd-place digits and the even-place digits is 0 or divisible by 11 | 2,915 → (2+1) and (9+5): 15 − 3 = 12 ✗ · 4,829 → (4+2)=6, (8+9)=17, 17 − 6 = 11 ✓ |

### Worked example

*Is 46,530 divisible by 6?*
It ends in 0, so it is divisible by **2**. Digit sum = 4+6+5+3+0 = 18, which is divisible
by **3**. Since it passes both tests, **yes, it is divisible by 6**.

## 2. TYPES OF NUMBERS

| Type | Meaning | First members |
|---|---|---|
| **Even** | Divisible by 2 | 2, 4, 6, 8, 10 … |
| **Odd** | Not divisible by 2 | 1, 3, 5, 7, 9 … |
| **Prime** | Exactly two factors: 1 and itself | 2, 3, 5, 7, 11, 13, 17, 19 |
| **Composite** | More than two factors | 4, 6, 8, 9, 10, 12, 14, 15 |
| **Square** | A number × itself | 1, 4, 9, 16, 25, 36, 49, 64, 81, 100 |
| **Cubic** | A number × itself × itself | 1, 8, 27, 64, 125, 216 |
| **Triangular** | Dots that form a triangle: add 1, then 2, then 3 … | 1, 3, 6, 10, 15, 21, 28, 36 |

### Important Points

- **2 is the only even prime number.**
- **1 is neither prime nor composite** — it has only one factor.
- 64 is both a **square** number (8 × 8) and a **cubic** number (4 × 4 × 4).
- Triangular numbers use the rule **n × (n + 1) ÷ 2**. The 7th triangular number = 7 × 8 ÷ 2 = **28**.

## 3. NUMBER PATTERNS AND SEQUENCES

### Definitions

**Sequence:** A list of numbers arranged according to a rule.

**Term:** Each number in a sequence.

**Common difference:** The number added (or subtracted) each time in an adding sequence.

### How to find the rule

1. Find the difference between the terms. If it is the same each time, the rule is **add** or **subtract**.
2. If not, try **multiplying** or **dividing**.
3. If still not, look at the second differences, or check for squares, cubes or triangular numbers.

### Worked examples

| Sequence | Rule | Next two terms |
|---|---|---|
| 3, 7, 11, 15, … | Add 4 | **19, 23** |
| 100, 92, 84, 76, … | Subtract 8 | **68, 60** |
| 2, 6, 18, 54, … | Multiply by 3 | **162, 486** |
| 1, 4, 9, 16, … | Square numbers | **25, 36** |
| 1, 8, 27, 64, … | Cubic numbers | **125, 216** |
| 1, 3, 6, 10, … | Triangular (add 2, 3, 4 …) | **15, 21** |
| 1, 1, 2, 3, 5, 8, … | Add the two numbers before | **13, 21** |
| 2, 5, 11, 23, … | × 2 then + 1 | **47, 95** |

### Finding any term of an adding sequence

For 3, 7, 11, 15 … the first term is 3 and the common difference is 4.

**nth term = first term + (n − 1) × common difference**

The 10th term = 3 + (10 − 1) × 4 = 3 + 36 = **39**

# KEY DEFINITIONS

| Term | Meaning |
|---|---|
| Divisible | Divides exactly with no remainder |
| Factor | A number that divides another exactly |
| Multiple | The answer when a number is multiplied by a whole number |
| Prime number | A number with exactly two factors |
| Composite number | A number with more than two factors |
| Square number | The product of a number multiplied by itself |
| Cubic number | The product of a number multiplied by itself three times |
| Triangular number | A number of dots that can form a triangle: 1, 3, 6, 10 … |
| Sequence | A list of numbers following a rule |
| Common difference | The fixed amount added each time in a sequence |

---

# IMPORTANT FACTS TO REMEMBER

- Divisible by 3 → **add the digits**. Divisible by 9 → add the digits too.
- Divisible by 6 → must pass **both** the 2 test and the 3 test.
- Divisible by 4 → look at the **last two** digits; by 8 → the **last three**.
- 2 is the only even prime; 1 is neither prime nor composite.
- Triangular numbers: 1, 3, 6, 10, 15, 21, 28 — rule n(n + 1) ÷ 2.
- nth term of an adding sequence = first term + (n − 1) × common difference.

---

# EXAMINATION POINTS

- "Which of these is divisible by 9?" — add the digits.
- "Give the next number: 1, 3, 6, 10, …" — 15 (triangular).
- "Which number is both square and cubic?" — 64 (also 1).
- "Name the first four composite numbers" — 4, 6, 8, 9.
- Sequences that grow fast are usually **multiplying** sequences.

---

# COMMON MISTAKES TO AVOID

- Saying 1 is a prime number.
- Saying 9 is prime — it has factors 1, 3 and 9.
- Testing only for 2 when the question asks about 6.
- Continuing a sequence by guessing instead of finding the difference first.
- Confusing square numbers (4, 9, 16) with even numbers.

# REVISION QUESTIONS

1. Which of these numbers is divisible by 3: 4,517 or 4,518? Show your working.
2. Test whether 7,236 is divisible by 4.
3. Test whether 51,840 is divisible by 6.
4. List all the prime numbers between 20 and 40.
5. List the first five composite numbers.
6. Write the first six triangular numbers.
7. Write the first five cubic numbers.
8. Find the next two terms: 5, 12, 19, 26, …
9. Find the next two terms: 3, 6, 12, 24, …
10. Find the missing number: 1, 4, 9, __, 25, 36.
11. Find the 12th term of the sequence 4, 9, 14, 19, …
12. Which number between 60 and 70 is both a square and a cubic number?
13. What is the 9th triangular number?
14. Find the next two terms: 1, 1, 2, 3, 5, 8, 13, …
15. A number is divisible by 9 and its digits add up to 27. Write any one such three-digit number.

# ANSWERS TO REVISION QUESTIONS

1. 4+5+1+7 = 17 (not divisible by 3); 4+5+1+8 = 18 (divisible by 3). So **4,518** is divisible by 3.
2. The last two digits are 36, and 36 ÷ 4 = 9. **Yes, it is divisible by 4.**
3. It ends in 0, so it is divisible by 2. Digit sum = 5+1+8+4+0 = 18, divisible by 3. **Yes, it is divisible by 6.**
4. 23, 29, 31, 37.
5. 4, 6, 8, 9, 10.
6. 1, 3, 6, 10, 15, 21.
7. 1, 8, 27, 64, 125.
8. The rule is add 7 → **33, 40**.
9. The rule is multiply by 2 → **48, 96**.
10. **16** (the square numbers).
11. First term 4, common difference 5. 12th term = 4 + (12 − 1) × 5 = 4 + 55 = **59**.
12. **64** — it is 8 × 8 and also 4 × 4 × 4.
13. 9 × 10 ÷ 2 = **45**.
14. Add the two numbers before → **21, 34**.
15. Any three-digit number whose digits add to 27, for example **999** (9 + 9 + 9 = 27).
