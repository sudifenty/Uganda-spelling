## 1. ALGEBRAIC EXPRESSIONS

### Definitions

**Algebra:** The part of Mathematics where letters stand for unknown numbers.

**Variable (unknown):** The letter used, such as x, y, a or n.

**Term:** A single part of an expression: in 5a + 3b, the terms are 5a and 3b.

**Like terms:** Terms with exactly the same letter, such as 5a and 2a.

**Coefficient:** The number in front of the letter — in 7y the coefficient is 7.

### Simplifying

Only **like terms** can be added or subtracted.

| Expression | Simplified |
|---|---|
| 5a + 3a | **8a** |
| 9y − 4y | **5y** |
| 5a + 3b − 2a + 4b | **3a + 7b** |
| 4x + 7 − x + 2 | **3x + 9** |
| 6m + 2n − 6m | **2n** |

### Removing brackets

Multiply everything inside the bracket by what is outside.

- 3(x + 4) = **3x + 12**
- 5(2a − 3) = **10a − 15**
- 2(x + 3) + 4(x − 1) = 2x + 6 + 4x − 4 = **6x + 2**
- −2(y − 5) = **−2y + 10**

## 2. SUBSTITUTION

### Definition

**Substitution:** Replacing the letters with the numbers they stand for and working out the answer.

### Worked examples

*Given a = 3, b = 2 and c = 5:*

| Expression | Working | Answer |
|---|---|---|
| 2a + 3b | 2(3) + 3(2) = 6 + 6 | **12** |
| 5c − 4a | 5(5) − 4(3) = 25 − 12 | **13** |
| abc | 3 × 2 × 5 | **30** |
| a² + b² | 9 + 4 | **13** |
| (c − b) ÷ a | (5 − 2) ÷ 3 = 3 ÷ 3 | **1** |

**Remember BODMAS when substituting.**

## 3. SOLVING EQUATIONS

### Definition

**Equation:** A mathematical statement with an equals sign, showing that two sides are equal.

### The golden rule

**Whatever you do to one side, do to the other side.** Work backwards: undo addition with subtraction, and undo multiplication with division.

### Worked examples

1. *Solve 3x + 5 = 20*
   3x = 20 − 5 = 15 → x = 15 ÷ 3 = **5**
   *Check:* 3(5) + 5 = 20 ✓

2. *Solve 7y − 8 = 27*
   7y = 27 + 8 = 35 → y = **5**

3. *Solve 2(x − 3) = 10*
   2x − 6 = 10 → 2x = 16 → x = **8**

4. *Solve 5n + 2 = 3n + 12* (unknown on both sides)
   5n − 3n = 12 − 2 → 2n = 10 → n = **5**

5. *Solve x/4 + 3 = 7*
   x/4 = 4 → x = **16**

### Word problems

*A number is multiplied by 4 and then 7 is added. The answer is 43. Find the number.*
Let the number be n. 4n + 7 = 43 → 4n = 36 → n = **9**

*Ann is 5 years older than Ben. Together they are 33 years old. How old is each?*
Let Ben be x. Then x + (x + 5) = 33 → 2x + 5 = 33 → 2x = 28 → x = 14.
**Ben is 14 and Ann is 19.** (14 + 19 = 33 ✓)

*The length of a rectangle is twice its width. Its perimeter is 36 m. Find the length and the width.*
Let the width be w; the length is 2w. Perimeter = 2(w + 2w) = 6w = 36 → w = 6.
**Width 6 m, length 12 m.**

## 4. INEQUALITIES AND SOLUTION SETS

### The signs

| Sign | Meaning |
|---|---|
| > | is greater than |
| < | is less than |
| ≥ | is greater than or equal to |
| ≤ | is less than or equal to |

### Solving

Solve an inequality just like an equation.
**One special rule:** if you multiply or divide both sides by a **negative** number, the sign turns round.

### Worked examples

1. *Solve 2x + 3 < 11*
   2x < 8 → x < **4**

2. *Solve 3y − 4 ≥ 11*
   3y ≥ 15 → y ≥ **5**

3. *Solve 5 − x > 2*
   −x > −3 → **x < 3** (the sign turned round when dividing by −1)

### Solution sets

**Solution set:** The set of all the values that make the inequality true, usually taken from the whole numbers or counting numbers unless told otherwise.

- *Write the solution set of x < 4, where x is a counting number.*
  **{1, 2, 3}**
- *Write the solution set of y ≥ 5, where y is a whole number less than 9.*
  **{5, 6, 7, 8}**
- *Write the solution set of 2x + 1 ≤ 9, where x is a whole number.*
  2x ≤ 8 → x ≤ 4 → **{0, 1, 2, 3, 4}**

### Showing an inequality on a number line

Use an **empty circle** for > or < (the number itself is not included), and a **filled circle** for ≥ or ≤ (the number is included). Draw an arrow in the direction of the answer.

# IMPORTANT FACTS TO REMEMBER

- Only **like terms** can be added or subtracted: 3a + 4b cannot be simplified further.
- Multiply **everything** inside a bracket by the term outside.
- Whatever you do to one side of an equation, **do to the other**.
- Always **check** your answer by putting it back into the equation.
- Multiplying or dividing an inequality by a **negative** number **turns the sign round**.
- Counting numbers start at 1; whole numbers start at 0. Read the question carefully.

---

# EXAMINATION POINTS

- 5a + 3b − 2a + 4b = 3a + 7b.
- 3(x + 4) = 3x + 12.
- If a = 3 and b = 2, then 2a + 3b = 12.
- 3x + 5 = 20 → x = 5.
- 2x + 3 < 11 → x < 4, and the solution set of counting numbers is {1, 2, 3}.
- Word problems: **let the unknown be a letter first**, then form the equation.

---

# COMMON MISTAKES TO AVOID

- Adding unlike terms: 3a + 4b is **not** 7ab.
- Multiplying only the first term inside a bracket.
- Forgetting to change the sign when a term crosses the equals sign.
- Forgetting to turn the inequality sign round after dividing by a negative.
- Including 0 in a solution set of counting numbers.

# ANSWERS TO REVISION QUESTIONS

1. **9a**
2. **3x + 5y**
3. 8m + 12 − 5 = **8m + 7**
4. 3x + 6 + 2x − 8 = **5x − 2**
5. 3(4) + 2(6) = 12 + 12 = **24**
6. 25 − 6 = **19**
7. 4x = 24 → x = **6**
8. 9y = 45 → y = **5**
9. 3n − 6 = 18 → 3n = 24 → n = **8**
10. 6k − 2k = 20 − 4 → 4k = 16 → k = **4**
11. x/5 = 5 → x = **25**
12. 3x < 15 → **x < 5**
13. 2y ≥ 12 → y ≥ 6. Solution set = **{6, 7, 8}**
14. 2n + 9 = 35 → 2n = 26 → n = **13**
15. Let width = w, length = w + 3. 2(w + w + 3) = 26 → 4w + 6 = 26 → 4w = 20 → w = 5. **Width 5 m, length 8 m** (perimeter 2 × 13 = 26 ✓)

# P.7 QUICK REVISION

- Add only **like terms** · multiply the whole bracket
- Substitute, then use **BODMAS**
- Equation: do the same to **both sides**, then **check**
- Inequality: same steps, but **flip the sign** when dividing by a negative
- Solution set: counting numbers start at **1**, whole numbers at **0**
- Word problems: name the unknown, form the equation, solve, check
